# ISC2 - AI Security

Interactive study site for the ISC2 AI Security pilot exam (15 December 2026), built from a 32-day study plan.

- **Today / Plan**: daily learn and recall tasks with linked free sources, checkboxes and notes
- **Tasks**: coverage of all 41 official tasks
- **Quiz**: 30 practice questions, chosen adaptively (Thompson sampling over per-domain Beta posteriors)
- **Cards**: flashcards
- **ML Lab**: TF-IDF search and a Naive Bayes domain classifier, both running in the browser

Static site, no build step, no dependencies. Open `index.html`, or enable GitHub Pages (Settings, Pages, deploy from branch `main`, root).

Unofficial. Practice questions are self-study aids, not official ISC2 items. Progress is stored in the browser's localStorage.
